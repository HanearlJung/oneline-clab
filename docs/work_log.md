# C-Lab 법인영업 타깃 발굴 데모 — 작업 로그

삼성증권 C-Lab PoC. `삼성_정형화데이터_컨펌요청_20260610_최종.xlsx` 7개 항목 중
보호예수(두나미스 기보유)를 뺀 6개 항목을 상장사 100개사 실제 공시로 채운다.

## 2026-08-07

### 접근 방식 확정

**OpenDART API 키를 쓰지 않는다.** 키는 있으나 등록 IP에서만 동작하고 등록에 1~2일이
걸린다. 대신 DART 공개 웹(`dart.fss.or.kr`)을 그대로 쓴다. 인증 없이 열린다.

| 용도 | 엔드포인트 |
|---|---|
| 공시검색 | `dsab007/detailSearch.ax` |
| 문서 목차 | `dsaf001/main.do?rcpNo=` |
| 본문 수신 | `report/viewer.do` (목차가 준 offset/length 구간만) |

**섹션 경계를 추정하지 않는다.** DART 원문이 경계를 직접 갖고 있다.
- 목차 노드가 섹션별 `offset`/`length`를 준다.
- 주석 안에는 `<A name='tocN'>제목</A>` 앵커가 있다.
- 앵커가 없는 수기 작성 문서(약 36%)는 텍스트 최상위 제목(`N. 제목`)으로 나눈다.

**추출 분담**
- 주석(금융자산·퇴직연금) — 회사마다 표 구조·명칭이 달라 **직접 읽어서** 추출
- 이벤트 공시(자사주·담보·최대주주변경) — 금융위 서식이 고정이라 항목명으로 추출.
  직접 읽은 원문(KT&G·경인전자·스맥)과 대조해 값 일치 확인함

### 사고 및 원인

**DART IP 차단 (복구됨).** 거래소공시(I001) 505페이지를 0.3초 간격으로 전수 훑다가
차단당했다. 애초에 5만 건을 훑을 이유가 없었다.
- 요청 간격 1.5초, 실패 시 최대 5분 백오프, 세션 재생성
- 페이지 단위 디스크 캐시 → 중단돼도 받은 페이지는 다시 안 받음
- **표적 검색으로 전환**: 719페이지 → 약 150페이지

**`reportName`은 완전일치다.** "자기주식" 같은 부분 문자열은 0건이 나온다.
이 때문에 자사주·담보 커버리지가 0이었다. 정확한 보고서명 6종으로 교체해 해결.

| 보고서명 |
|---|
| 주요사항보고서(자기주식처분결정) / (자기주식취득결정) |
| 최대주주변경 / 최대주주변경을수반하는주식양수도계약체결 |
| 최대주주변경을수반하는주식담보제공계약체결 |
| 주식등의대량보유상황보고서(일반) |

**정기보고서 검색 결과에 `rcp_no`가 이미 있다.** 회사별 검색 100회를 없앴다.

**대량보유보고서에서 담보 노드를 놓쳤다.** "가장 큰 노드"(제3부 세부변동내역)를
집는 바람에 담보 계약이 든 "2. 보유주식등에 관한 계약"을 통째로 빠뜨렸다.
유형별 노드 우선순위를 지정해 해결.

### 설계 판단 (영업 관점)

**회계 분류가 아니라 "가져올 수 있는 물량"을 지표로 쓴다.**

| 탭 | 잘못된 지표 | 쓰는 지표 |
|---|---|---|
| 퇴직연금 | 확정급여채무(부채) | **원금보장형 적립금** + 차기 기여금 |
| 금융상품 운용 | 금융자산 총액 | **예치성 자금 + 수익증권류** (FVOCI 전략지분 제외) |
| 주식담보 | 담보주식 수 | **총 대출금액**(없으면 담보 평가액) + 최근접 만기 |
| 대주주 자금운용 | 지분율 | **인수자금**(공시값) 또는 지분율×시총 |

**날짜가 없는 항목에 가짜 D-day를 만들지 않는다.** 퇴직연금은 날짜 개념이 없고
금융자산은 개별 만기가 아니라 구간으로만 공시된다. 탭마다 시간 열의 의미를 다르게 뒀다
(`dday` / `elapsed` / `range` / `none`).

**퇴직연금 영업 상황 3분류** — 적립률 하나로 줄 세우면 "적립률 115%인데 적립률이 낮아
우선 접촉"이라는 자기모순이 생긴다.
- 추가적립 필요 (적립률 95% 미만)
- 원금보장형 편중 (원금보장형 60% 이상)
- 운용기관 경쟁 (그 외)

**담보는 회사별로 합산한다.** 같은 대주주가 증권사별로 쪼개 실행해 한 회사에
20~30건씩 나온다. 898행 → 55행(회사당 1행).

**국민연금 지분 변동은 대주주 자금운용에서 뺀다.** 기관 지분율이 내려가 최대주주가
바뀐 것을 "오너 매각대금 유입"으로 읽으면 틀린 영업이 된다.

### 주석 추출에서 판단한 것들

**단위가 회사마다 다르다.** 백만원·천원·천USD가 섞여 있고 한 문서 안에서도 표마다
다르다(에코프로는 본표가 천원인데 차기 기여금만 백만원). 원문 단위를 그대로 기록하고
환산은 화면 빌드 단계에서 한다. 단위를 모르면 `null` — 추측하지 않는다.

**DC만 운영하는 회사는 퇴직연금 탭에서 뺀다.** 셀트리온이 그렇다. DB 적립금이 없으면
법인이 운용을 맡길 자산 자체가 없다.

**금융회사는 금융상품 운용 탭에서 뺀다.** 키움증권 FVTPL 46.7조, 한화 58.8조는
자기매매·보험 운용자산이지 증권사에 맡길 여유자금이 아니다.
(제외: 키움증권·미래에셋증권·DB손해보험·한화)

**두산밥캣은 원문 단위가 천USD다.** 환산 근거가 공시에 없어 제외했다.

**현대차 금융업채권 134조는 뺐다.** 현대캐피탈 등의 영업자산이라 운용 대상이 아니다.
FVOCI 4.2조도 원문에 "전략적 투자목적"으로 명시되어 제외.

**사외적립자산 구성이 곧 영업 세그먼트다.**
- 원리금보장형(예적금·이율보증형보험·적격보험계약·원리금보장 ELB) → 실적배당 전환 대상
- 실적배당형(투자펀드·지분상품·채무상품) → 이미 운용 중, 운용기관 교체 대상
- 구분이 공시되지 않으면 `null` (한화오션의 '그 밖의 자산' 등)

**적립률 95% 미만만 '추가적립 필요'로 부른다.** 99.6%를 부족이라 부르면 과장이다.
