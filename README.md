# 법인영업 타깃 발굴 — 삼성증권 C-Lab PoC

상장사 100개사의 **실제 DART 공시**에서 뽑은 데이터로, 증권사 법인영업 담당자가
어떤 기업에 무엇을 제안할지 바로 판단할 수 있게 만든 화면입니다.

**→ [화면 보기](https://hanearljung.github.io/oneline-clab/)**

---

## 무엇을 보여주는가

영업 목적 6가지별로 대상 기업과 근거, 접촉 시점, 제안 방향을 보여줍니다.

| 탭 | 영업 지표 | 원천 공시 |
|---|---|---|
| 금융상품 운용 | 예치성 자금 + 수익증권류 | 정기보고서 주석 `금융상품` |
| 퇴직연금 | 원금보장형 적립금 + 차기 기여금 | 정기보고서 주석 `종업원급여` |
| 자사주 처분 | 처분 예정 규모 / 보유 자사주 | 주요사항보고서 `자기주식 처분·취득결정` |
| 주식담보대출 | 총 대출금액 + 최근접 만기 | 대량보유상황보고서 `보유주식등에 관한 계약` |
| 임직원 주식보상 | 미행사분 평가액 | 정기보고서 `주식매수선택권` |
| 대주주 자금운용 | 양수도 대금 | 거래소공시 `최대주주변경` |

### 설계 원칙

**회계 분류가 아니라 "가져올 수 있는 물량"을 지표로 쓴다.**
확정급여채무(부채)나 금융자산 총액은 영업사원이 쓸 수 없는 숫자다.
원금보장형에 묶인 적립금, 저수익 예치자금처럼 실제로 갈아탈 수 있는 금액을 전면에 둔다.

**날짜가 없는 항목에 가짜 D-day를 만들지 않는다.**
퇴직연금은 날짜 개념이 없고, 금융자산은 개별 만기가 아니라 구간으로만 공시된다.
탭마다 시간 열의 의미를 다르게 둔다 (`dday` / `elapsed` / `range` / `none`).

**이미 지난 이벤트는 영업 기회가 아니다.**
자사주 처분예정기간이 끝났거나 담보 만기가 지난 건은 목록에서 뺀다.
대신 보유 자사주처럼 향후 물량을 나타내는 지표로 대체한다.

**없으면 없다고 한다.**
값이 공시되지 않은 기업은 해당 탭에서 제외하고, 커버리지 배지로 몇 개사가
해당하는지 그대로 표기한다.

## 데이터 출처

전부 금융감독원 전자공시시스템(DART) 공개 공시다. 각 행의 "원문 보기"는
그 값을 뽑은 실제 공시로 연결된다.

기준일은 기업마다 다르다. 정기보고서는 결산월이 다르고, 이벤트 공시는 발생일이
제각각이기 때문이다. 행마다 기준일을 함께 표기한다.

## 구조

```
index.html              화면 (데이터는 fetch 로 주입)
data/
  site_data.json        화면이 읽는 데이터
  companies.json        대상 100개사 + 최신 정기보고서 rcp_no
  market_master.json    종목코드·업종·시총·주가 (KIND + 네이버금융)
extracted/{corp_code}.json   기업별 추출 결과
scripts/                수집·추출·빌드 스크립트
docs/
  work_log.md           작업 로그 (판단 근거와 사고 기록)
  data_schema.md        데이터 계약
legacy-seed/            이전 시드 데이터 빌드 (참고용 보존)
```

### 재현

```bash
python3 scripts/step0b_market_master.py     # 종목코드·업종·시총
python3 scripts/step0_select_companies.py   # 100개사 선정 + rcp_no
python3 scripts/step1_fetch_and_slice.py    # 정기보고서 주석 수집
python3 scripts/step2_fetch_events.py       # 이벤트 공시 수집
python3 scripts/step2b_extract_events.py    # 이벤트 값 추출 (고정 서식)
python3 scripts/step3_build_site_data.py    # 화면 데이터 빌드
```

주석(금융자산·퇴직연금)은 회사마다 표 구조가 달라 자동 추출하지 않는다.
`slices/` 조각을 직접 읽어 `extracted/*.json` 에 기록한다.

> DART 공개 웹은 짧은 간격으로 대량 요청하면 IP가 차단된다.
> `scripts/dart.py` 는 요청 간격 1.5초, 실패 시 최대 5분 백오프로 설정돼 있다.
> 이 값을 낮추지 말 것.

## 현재 상태

이벤트 기반 3개 탭(자사주·담보·대주주)은 추출이 끝났고, 주석 기반 2개 탭
(금융자산·퇴직연금)은 시총 상위부터 채우는 중이다. 탭별 커버리지는 화면 배지에
그대로 나온다.
